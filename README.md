# 임유열 · 건축 포트폴리오

조선대학교 건축학과에서 진행한 1·2학년 건축설계 작업을 소개하는 HTML 홈페이지입니다.

이번 **자기소개 홈페이지 전체를 하나의 개발 프로젝트**로 구성했습니다. 건축 작품은 학년·학기별로 정리된 상세 페이지에서 소개합니다.

## 바로 열기

`index.html`을 더블 클릭하면 브라우저에서 열립니다. 설치나 로그인이 필요하지 않습니다. 인터넷 연결 없이도 작품 사진, 학년별 이동, 이미지 확대 기능을 이용할 수 있습니다.

## 구성

- `index.html` — 자기소개, 학년별 목록, 대표작
- `year-1.html` — 2021년 1·2학기, 4개 작업
- `year-2.html` — 2022년 1학기 / 2024년 2학기, 8개 작업
- `year-3.html`, `year-4.html` — 자료 추가 예정
- `projects/` — 12개 작품 상세 페이지
- `assets/` — 스타일, 갤러리 기능, 웹용으로 최적화한 작품 이미지
- `content.json` — 이름, 소개, 학년 설명, 작품별 글과 사진 목록
- `build.py` — `content.json`에서 HTML을 생성하는 도구
- `sources/` — PPT 원본과 사용 이미지의 출처 기록

## 내용 수정

1. `content.json`에서 소개 글, 작품 설명, 학년·학기 정보를 수정합니다.
2. 새 사진은 `assets/images/`에 넣고 `sources/asset-sources.json`에 크기와 출처를 등록합니다. 현재 이미지에는 큰 보기용 `.webp`와 목록용 `-thumb.webp`가 있습니다.
3. 이 폴더에서 `python build.py`를 실행해 HTML을 다시 만듭니다.
4. `index.html`을 열어 확인하고 GitHub에 저장합니다.

HTML을 직접 수정할 수도 있습니다. 다만 `build.py`를 다시 실행하면 생성된 HTML의 직접 수정 사항이 덮어써지므로, 지속적으로 유지할 내용은 `content.json` 또는 `build.py`에 반영하세요.

## 원본 자료

상위 폴더의 `1학년/1학기`, `1학년/2학기`, `2학년/1학기`, `2학년/2학기`에 있는 네 개의 PPT를 바탕으로 작성했습니다. 원본 PPT는 그대로 보존하며 이 저장소에는 포함하지 않습니다. 교수 강의자료와 타 학생의 예시는 개인 작품으로 소개하지 않았습니다. 팀 사례 분석과 기존 건축물의 재현은 공동작업·사례 연구로 구분했습니다.

2학년 2학기는 원본 표지에 기재된 **2024년**을 따릅니다. 2학년 1학기의 2022년과 이어지는 연도로 임의 변경하지 않았습니다. 자세한 내용 기준은 [자료 정리 기록](sources/CONTENT_NOTES.md)을 참고하세요.

## GitHub 저장과 홈페이지 공개

소스가 GitHub에 저장되는 것과 웹사이트가 공개되는 것은 별개입니다. 최초 저장은 비공개 저장소를 기준으로 합니다. 공개하려면 저장소의 공개 범위와 GitHub Pages 설정을 별도로 정하세요.

이 사이트는 빌드된 HTML이 포함된 순수 정적 사이트이므로 GitHub Pages에 사용할 수 있습니다. Pages에서 브랜치의 `main` / `/ (root)`를 게시 대상으로 설정하면 됩니다. 별도 서버나 데이터베이스는 필요하지 않습니다. 상대 경로를 사용해 프로젝트 저장소의 하위 URL에서도 작동합니다.

## 검증

- 17개 페이지의 이미지 로딩과 브라우저 오류 확인
- PC·태블릿·휴대폰 폭에서 가로 넘침 확인
- 학년과 학기 이동, 이미지 확대·이전·다음·Esc 닫기 확인
- 파일을 직접 여는 방식에서도 갤러리 기능 확인

사진과 도면, 설계 내용의 권리는 각 원저작자에게 있습니다. 이 저장소는 작품의 재사용을 허가하는 오픈소스 라이선스를 부여하지 않습니다.
